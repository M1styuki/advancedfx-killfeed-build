# Seven-map storm controller

The user explicitly keeps materials/skybox/sky_rain_night_01.vmat_c. Never issue a sky command or alter that selection. Overall scene exposure/grading still affects scene pixels; preserving the sky selection is not a claim that its pixels bypass all postprocessing. Extend the existing seven-map rain/contact/wet-material controller, retaining its independent killfeed and strong-resource ownership repairs. No separate ReShade installation or local build environment is required.

## Filtered kill trigger

DeathMsg.cpp HandleHudDeathNotice notifies MirvWeatherStorm_VisibleKill only after the complete filter loop and block-return decision, and only when the filter list and real attacker/victim controllers exist. The notification is not placed in the DeathPanel listener. With attackerMatch=!xTrace block=1 lastRule=1, the kept player's kills trigger; blocked kills do not. The original parser resolves xTrace at rule creation, so use the filter's final result instead of tracing the current camera again. World kills and suicides are rejected; duplicate tick/attacker/victim tuples are suppressed while distinct victims remain distinct events. Seek/reset clears queued and recent events. Normal accelerated playback accepts events within the same bounded tick span; seek jumps discard catch-up events.

Ambient trigger uses demo seconds, default period 30 seconds. Modes demo/kills/both/off are independent of the weather master. Pausing does not advance the schedule; enabling does not replay all elapsed ambient slots. Disable, reset, map changes and jumps restore state and stop owned audio/particles. Native particle appearance itself is not promised pixel-identical across recordings.

## Native flash particles and grading

Use the actual native storm_lightning_01_cloud instantaneous burst and storm_lightning_01_thin path, whose sequential path ends at CP1. Set CP0 and CP1, retain the definitions while owned, and destroy only matching manager/index/record objects. Limit live transient objects and clean them on disable/map/seek. Do not spawn train_lightning merely because of its name: inspection showed it also references coal-dump/smoke children. No local game asset bytes are distributed or uploaded.

MirvWeatherRender.cpp provides an original small SM5 grading shader; standard exposure, luma/saturation, highlight compression, slight cool balance and shadow lift are inspired by documented postprocessing techniques, not copied proprietary qUINT code. It executes through HLAE's existing before-UI marker; no new Present detour is installed. Save/restore all touched D3D11 shaders and class instances, IA state, PS slot-zero resource/sampler/constants, render targets/depth view, viewport, blend/depth/raster state. Copy the source color target before sampling, reject MSAA/array/mip/depth/data capture formats, and release cached GPU objects when devices or target formats change. Shader compilation and actual render calls have diagnostic status. Preserve exact black and fully white pixels; additionally skip grade and restore exposure while the observed pawn's valid active flash interval and alpha indicate a flash. Flash offsets are cached optional schema, not guessed fields.

Independent immediate Release debug controls: weather_sun, weather_exposure, weather_grade, weather_lightning, weather_lightning_light, weather_rainsound, weather_thunder. All default on under the weather master/storm mode, without requiring mirv_pov. Turning particle lightning off does not disable scheduled illumination/thunder. Storm off preserves the base rain/ground/contact profile. Sun-card suppression is scoped to known world scene-record layouts and flushes before skipping a record, preserving contiguous native batch assumptions. The user-selected sky material is never replaced.

## Validation boundaries

Verify current module hashes, native light/owned-audio call-site ABI, unique stop signature, selected particle control points and looping audio metadata. Source whitespace and Windows Release x64 must pass. CI also compiles the exact embedded VS/PS entry points with fxc. Verify downloaded binary and corresponding source before installing. All seven-map dark lighting, indoors, actual audio, kept/blocked kill triggers, multiple kills, pause/rewind, full POV flash, HUD, recording and complete restoration still require user in-game acceptance. Do not interpret counters or compilation alone as visible/audible success. No private player data or raw dumps are published.
